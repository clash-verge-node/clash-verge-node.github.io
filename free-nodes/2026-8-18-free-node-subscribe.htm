Shadowrocket 是一款专为 iOS 系统设计的代理客户端，允许用户手动添加并管理各种网络节点（如Shadowsocks、V2Ray、Trojan等），以绕过地域限制、访问全球互联网。它具有如下优势：

  • 自定义度高：支持规则分流、手动添加节点、脚本等高级配置。

  • 隐私保护：所有连接可通过加密协议进行数据传输，保障用户信息安全。

  • 多协议兼容：支持主流的科学上网协议，适应多种场景和服务。

尽管它未在中国大陆App Store上架，但通过非大陆Apple ID，用户仍然可以轻松下载并使用。

  1. 使用非中国大陆Apple ID登录App Store

  2. 搜索“Shadowrocket”，下载安装（售价约2.99美元）

  3. 安装完成后打开应用

注意：需iOS 9以上系统支持。

第二步：获取澳洲节点信息

假设你已通过VPN服务商购买了澳洲节点，或获取了他人分享的节点信息（包括服务器地址、端口、密码、加密方式、协议等）。

常见格式如下（Shadowsocks）：

第三步：手动添加节点

  1. 打开Shadowrocket主界面

  2. 点击右上角 “+” 添加节点

  3. 选择节点类型（如Shadowsocks）

  4. 填写节点参数

  5. 点击“完成”保存

如果你获取的是订阅链接，可点击“订阅” > 添加URL > 自动拉取节点列表

第四步：启用节点连接

  1. 在首页选择刚才添加的澳洲节点

  2. 切换“连接”开关至开启状态

  3. 查看系统VPN图标是否亮起

  4. 访问如 ip.skk.moe 或 whatismyipaddress.com 确认IP是否切换成功

五、节点优化与安全设置建议

Shadowrocket虽然功能强大，但仍需合理设置才能发挥最大效果。

? 1. 启用规则分流

  • 避免全局代理造成国内访问变慢

  • 建议使用规则订阅（如ACL4SSR规则）

? 2. 启用Kill Switch（网络切断保护）

防止VPN断线后暴露真实IP： 路径：设置 > 连接 > 启用“断线保护”功能

启用DoH（DNS over HTTPS）或自定义可信DNS（如8.8.8.8、1.1.1.1），防止DNS泄露。

FAQ

Mihomo 节点分组功能有什么优势？
分组管理可按延迟、地区或用途分类节点，并结合策略组实现自动分流。用户可快速选择最优节点，提高访问速度和稳定性，方便管理大量节点并优化维护效率。
如何安全地共享订阅链接而不泄露个人信息？
避免将私人订阅直接在公开场合分享，若需要共享可在服务端生成只读或限速专用订阅，并定期更换 token。对外公开时移除或隐藏用户识别字段，确保他人无法通过订阅追溯出个人账户信息。
Matsuri 节点排序功能如何提升访问效率？
Matsuri 会定期测速节点延迟，并结合策略组自动选择延迟低、稳定性高的节点处理不同流量。提升网页浏览、视频播放和游戏访问速度，减少掉线和卡顿。
Shadowrocket 能否自动更新订阅？
支持。Shadowrocket 可以设置定时更新周期，例如每隔 12 小时或每天自动刷新订阅链接，确保节点列表保持最新状态。这样无需手动更新即可长期稳定使用。
Sing-box 支持按 IP 段分流吗？
支持。Sing-box 可根据 IP 段将国内流量直连，国外流量走代理，结合策略组实现智能分流。这样可保证访问速度和稳定性，同时优化节点使用效率，提高网络体验。
Nekobox 是否可以管理多客户端节点？
可以。Nekobox 与 Shadowsocks、Clash 等客户端独立运行，互不干扰。结合策略组使用，可灵活分配节点，实现多客户端管理和流量优化。
Quantumult X 的自动策略组如何工作？
Quantumult X 的自动策略组可根据延迟、可用性或测速结果自动选择最优节点，用户无需手动切换。可在策略组设置中开启“延迟优先”或“可用性优先”模式以优化体验。
V2Ray 如何通过策略组优化海外网站访问？
策略组可根据延迟和地理位置自动选择最佳节点访问海外网站。结合路由规则，可实现国内流量直连，国外流量通过代理，提高访问速度，降低延迟和连接不稳定风险。
V2Ray 如何实现分流规则？
V2Ray 使用 routing 模块实现分流，可根据目标域名、IP、端口或协议类型决定流量走向。用户可自定义多个 outbound，并通过规则实现国内直连、国外代理等智能路由功能。
V2Ray 的 gRPC 模式适合哪些场景？
gRPC 支持多路复用和长连接，适合高并发访问和移动网络场景。相比 TCP 或 WebSocket，它可以减少握手次数，降低延迟，同时提高连接稳定性和吞吐量，特别适合游戏或即时通讯。
